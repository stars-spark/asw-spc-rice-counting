其面积与形状都接近单粒米，几何判据没有理由拒绝它。

\section{代码、数据与复现方式}
\label{app:repro}

这一节交代程序与数据的来源，便于老师核查。

\textbf{数据。} D1、D3 以及 D2 所用的单粒米素材均取自 Roboflow Universe 上的公开数据集
（CC BY 4.0 许可）\cite{ds_d1,ds_d3,ds_grains}；D2 由 \texttt{src/synth.py} 按固定随机种子生成，
重跑可得到相同的 40 张图与真值。第 \ref{sec:limit} 节提到的直尺照片来自文献\cite{ds_ruler}，
未用作测试集。

\textbf{代码与复现。} 环境为 Python 3.13，依赖 OpenCV、scikit-image 与 SciPy，
学生模型与 SAM 3 另需 PyTorch。各步骤分别实现于 \texttt{preprocess.py}（二值化与候选选择）、
\texttt{calibrate.py}（尺度自标定）、\texttt{segment.py} 与 \texttt{correct.py}（切分与复核）、
\texttt{counter.py}（主流程）、\texttt{baselines.py}（五种对比方法）。
运行 \texttt{python -m src.evaluate}、\texttt{src.ablation}、\texttt{src.robustness}、
\texttt{src.cost}、\texttt{src.student -{}-eval} 可分别重新生成正文各表，
表中数字均由脚本直接产出，未经手工修改。
