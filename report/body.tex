\section{引言}

本次作业要求数出照片里有多少粒米，并解决连体米粒计数不准的问题。

恰好我大二打过电赛和物联网设计竞赛，负责视觉循迹，目标识别。于是我先利用已有的知识做了初步尝试。

最初按最基本的思路做了一遍。先转灰度，再用 Otsu 法\cite{otsu1979}自动选一个阈值把米粒和背景分开，最后统计连通域的个数。连通域指二值图中连在一起的一片前景像素，正常情况下一粒米就是一个连通域。米粒互不接触时，这一流程没有问题。一旦两粒米挨在一起，它们在二值图中连成一块，只被计为 1 粒。米粒越密，漏计越多，见图 \ref{fig:problem}。
实测粘连率 80\% 时平均少数 38.9 粒，这条误差曲线见图 \ref{fig:curve}，也正是本次作业的难点所在。

\begin{cfigure}
  \centering
  \includegraphics[width=\textwidth]{problem_zoom.png}
  \caption{粘连导致漏计的局部放大。右图中橙色的一整块是一个连通域，其中实际有 2 粒米。}
  \label{fig:problem}
\end{cfigure}

于是我转向网上学习新方法，在查阅文献时注意到，这个问题在已发表的工作中也常被回避。
Kurade 等人\cite{kurade2023}的米质检测系统采用“腐蚀取标记结合注水分割”，
注水分割即 watershed 算法，常译作“分水岭算法”。
该文承认这一算法分不开互相接触的米粒，因而把这些米粒从数据集中剔除。
本文试着解决这一问题。

本文的工作可以概括为以下四点。
\begin{enumerate}
  \item 由程序从图像自身量出单粒米的尺寸与形状，后续判据均以此为单位，不预设固定的像素常数；
  \item 不预先指定颜色通道与阈值方式，而是把若干组合逐一试过，按一个打分函数自动选取；
  \item 以“又大又凹”的形状为条件，判断连通域是否为粘连块，再用注水分割切开；
  \item 切分后按面积与形状复核，并剔除硬币、边框等非米目标。
\end{enumerate}

在三组性质不同的数据上，上述方法的平均绝对误差为 2.75、0.25 与 0.50 粒，
优于本文实现的五种经典对比方法；粘连率 80\% 时误差约为直接统计连通域的四十四分之一。
在此之外，本文还用 SAM 3 的输出作伪标签蒸馏了一个 27 万参数的小网络，
详见第 \ref{sec:student} 节，在同一批测试图上它的总体误差为 0.68 粒，方法一为 0.48 粒。
代码、数据来源与复现方式见附录 \ref{app:repro}。

\section{相关工作}

分开粘连目标大致有两种思路。

一种是从轮廓入手。两粒米的接触处在轮廓上是一个凹点，找到凹点再连线切开。
Tan 等人\cite{tan2019}用这种方法处理粘连稻谷，
Avzalov 等人\cite{avzalov2025}进一步用椭圆拟合滤除假凹点。本文将后者实现为对比方法 B5。

另一种是从区域入手，先用注水分割\cite{vincent1991}切开，再修正结果。
Gamarra 等人\cite{gamarra2019}先以大小和凸性判断哪些区域需要切分，切开后再合并过碎的部分。
本文方法属于后一类，结构上与之相近；我实现该方法以后查文献，才发现有前辈用过类似的方法。

国内在谷物考种一类的任务上做过不少同类工作。凌云等人\cite{ling2005}较早把注水分割用在谷物籽粒上，
杨蜀秦等人\cite{yang2009}处理的正是连接在一起的米粒。
荀一等人\cite{xun2010}在连续腐蚀与膨胀的过程中找出两粒之间的公共区域，取其端点连线切开。
柳冠伊等人\cite{liu2014}把距离变换图当作地形图，沿山谷线切分。
他们还指出，这样一来就不必先由人工设定阈值去判断是否粘连。
这一点与本文用自标定量出判据的想法相近。
李文勇等人\cite{li2015}则先用形状因子判断一个区域是不是粘连，再定位分割点。

\section{方法一：几何方法}

方法一沿用常规的思路，先二值化，再找连通域，最后用注水分割把粘连的米粒切开。
不同之处在于，判断时用到的尺寸和门限都不预先设定，而是从每张图自身量出来。

整个流程分五步，见图 \ref{fig:flow}。第一步选出米粒所在的前景，第二步量出一粒米有多大，
第三步找出哪些连通域是几粒米粘在一起，第四步把这些粘连块切开，
第五步剔除硬币、木框、阴影这类不是米的区域，复核切分结果，并找回被去噪抹掉的米，
其中剔除的几道判断在程序里排在第三步之前。各步在一张合成图上的中间结果见图 \ref{fig:pipeline}。
下面先交代几个后文要用的概念，再按这五步依次说明。

\subsection{几个基本概念}

\textbf{距离变换 $D$} 是每个像素到最近背景像素的距离。
米粒中间的值大、边缘的值小，像一座山；两粒米贴合的地方是一道山谷。

\textbf{种子} 是告诉程序“这里有一粒米”的起点，只需落在米粒内部的一小块像素上。

\textbf{注水分割} 把距离变换取负值当作地形，每粒米陷成一个盆地，见图 \ref{fig:terrain}。
水从各个种子处涨起来，两股水相遇的地方就是切分线。
给几个种子就切成几块，所以一个粘连块被算作几粒，取决于种子怎么放。

\begin{cfigure}
  \centering
  \includegraphics[width=\textwidth]{terrain_3d.png}
  \caption{把距离变换取负值当作地形。(a) 为一个约 8 粒的粘连块，(b) 为它的三维地形，
  竖轴为距背景的像素距离，(c) 为注水后的切分结果。}
  \label{fig:terrain}
\end{cfigure}

\textbf{凸实度 $\rho$} 是区域面积与其凸包面积之比，凸包即包住该区域的最小凸多边形。
一粒米接近凸形，$\rho$ 接近 1；两粒粘在一起，接缝处凹进去，$\rho$ 会变小。

\subsection{第一步，选出米粒所在的前景}

最简单的做法是用 Otsu 法把灰度图分成亮暗两类。可是真实照片里，白米放在深色衬布上，
衬布又铺在浅色桌面上，画面有三个亮度层次。分两类只能切一刀，
无论切在哪里，总有一整片背景被划进前景，见图 \ref{fig:binfail}。
这片伪前景比所有米粒加起来还大，后面每一步都会被它带偏。

\begin{cfigure}
  \centering
  \includegraphics[width=\textwidth]{binarisation_failure.png}
  \caption{固定用灰度两类阈值的后果，蓝色为该二值图中最大的连通域。
  前景取亮或取暗都会多出一片巨大的伪前景。}
  \label{fig:binfail}
\end{cfigure}

所以本文不事先决定用哪个颜色通道、分几类、前景取亮还是取暗，
而是把这些组合都试一遍，用下式打分，选分数最高的一个。
\begin{equation}
  \mathrm{score} = N\sub{单} \cdot A_0 \cdot \gamma
  \label{eq:score}
\end{equation}
式中 $N\sub{单}$ 是大小接近一粒米的连通域个数，$A_0$ 是估计出的单粒面积，
$\gamma$ 是前景与紧邻背景的反差。前两项奖励“分出了许多大小一致的米粒”；
第三项用来排除噪声斑点，它们数量很多，却几乎没有反差。

选中的方案还要过一道合理性检查，米粒的长宽比和大小要在合理范围之内，
不通过就换下一个候选。低分辨率图里被误当成米粒的木框条纹，就是靠这道检查挡下的。

\subsection{第二步，量出一粒米有多大}

后面判断多大算大、多凹算凹，都需要一粒米作参照。
三组数据的米粒大小相差好几倍，固定的像素数难以通用，只能每张图现量。

做法是统计所有连通域的面积，取出现次数最多的那个大小作为单粒面积 $A_0$，
实现见代码 \ref{code:a0}。单独的米粒通常最多，粘连块的面积则落在 $A_0$ 的两倍、三倍附近。
面积先取对数，这些峰就变得等间距，更容易分辨，见图 \ref{fig:calib}。
起初取的是面积最小的那个峰，结果常常选中比米粒还小的碎屑。

有了 $A_0$，再从大小接近一粒米的连通域里量出短轴 $b_0$、凸实度 $\rho_0$ 和宽度 $w_0$，
作为后面各步的尺子。

\begin{lstlisting}[float=!htbp, caption={估计单粒面积 $A_0$}, label={code:a0}]
def estimate_a0(areas):
    """取对数面积分布的最高峰作为单粒米面积"""
    log_s = np.log(areas)
    kde = gaussian_kde(log_s)                 # 核密度估计，相当于平滑的直方图
    grid = np.linspace(log_s.min(), log_s.max(), 512)
    a0 = np.exp(grid[np.argmax(kde(grid))])   # 最高峰对应的面积
    # 再取 0.65~1.45 倍 A0 之间的连通域求平均，结果更稳
    band = areas[(areas >= 0.65 * a0) & (areas <= 1.45 * a0)]
    return band.mean() if len(band) > 0 else a0
\end{lstlisting}

\subsection{第三步，找出粘连块}
\label{sec:touch}

比一粒米大的连通域，未必是几粒粘在一起，也可能只是一粒偏大的米。
两粒米贴合处会凹进去一块，所以本文要求又大又凹才算粘连，实现见代码 \ref{code:touch}，
单粒与粘连块的对照见图 \ref{fig:criterion}。
起初只要大或凹占一条就算，结果在真实照片上把不少单粒也切开了。

这里也走过一段弯路。我原以为米粒只有几个像素宽时边缘锯齿很重，凸实度量不准，
于是短轴不足 4.5 像素时改看厚度，也就是面积与最大内切圆直径平方之比。
后来拿标注框逐块核对，发现这个担心并不成立。
D1 里短轴 3.7 至 4.5 像素的照片上，两粒粘连块的凸实度比单粒低 0.20，单粒几乎不低，照样分得开；
厚度判据反而分不开，三分之二的两粒块没被认出来。
在 D3 上，它还把木框边上的亮斑当成粘连块，再按面积折成好几粒。
米堆总会留下凹口，这些亮斑却和单粒一样凸，只看凹不凹就能排除。
所以现在各种尺度下都看凸实度，量化结果见第 \ref{sec:ablation} 节。

\begin{cfigure}
  \centering
  \includegraphics[width=0.7\textwidth]{touching_criterion.png}
  \caption{单粒与粘连块的对照。蓝色为区域本身，浅色为凸包多出的部分。
  橙圈为最大内切圆，它的直径即第 \ref{sec:correct} 节异物判据所用的宽度 $w$。}
  \label{fig:criterion}
\end{cfigure}

\begin{lstlisting}[float=!htbp, caption={判断一个连通域是不是粘连块}, label={code:touch}]
def is_touching(c, cal):
    """c 是一个连通域，cal 是自标定得到的单粒米参数"""
    if c.area <= 1.2 * cal.a0:            # 不比一粒米大，不算粘连
        return False
    return c.solidity < cal.rho0 - 0.06   # 又大又凹才算粘连
\end{lstlisting}

\subsection{第四步，切开粘连块}

判出粘连块之后，要决定放几个种子，也就是认定块里有几粒米。


关键在于看深度而不是距离。两粒米之间是一道深谷，一粒米内部只有浅浅的起伏。
于是对距离变换做 h-maxima，只保留比周围高出 $h$ 以上的峰作种子，
见图 \ref{fig:seeddepth} 与代码 \ref{code:split}。
$h$ 随短轴 $b_0$ 缩放，因为两粒米能靠多近取决于它们的宽度；
但不低于一个像素，因为距离变换本身就以像素计量，更小的起伏只是边缘的锯齿。

\begin{cfigure}
  \centering
  \includegraphics[width=\textwidth]{seed_depth.pdf}
  \caption{为什么看深度而不看距离。左为粘连块的距离变换，右为沿山脊的剖面。
  谷底低于橙色虚线，即比较低的峰矮出 $h$ 以上，两个峰各留一个种子。}
  \label{fig:seeddepth}
\end{cfigure}

这一步有个问题，我在检查效果图时才发现。h-maxima 作用在浮点的距离图上，
会把同一个平顶的峰碎成几小块，每块都成了种子，一粒米就被切成两半。
同一粒米上的碎块彼此很近，不同米粒的种子则隔得较远，
所以把相距不到约半粒米宽的种子并成一颗。

这个问题还牵连着另一个问题。碎块没合并时，$h$ 越小碎块越多，调参只好把 $h$ 调大；
$h$ 太大，又把饱满米粒之间那道凹陷部分抹平了，许多粘连块切不开。
两种错误在数量上碰巧抵消，总数看着是对的，效果图却明显不对。
合并碎块之后再把 $h$ 调小，两种错误都基本消失，量化结果见第 \ref{sec:ablation} 节。

\begin{lstlisting}[float=!htbp, caption={放种子并做注水分割}, label={code:split}]
def split_cluster(mask, cal, beta=0.1):
    dist = cv2.distanceTransform(mask, cv2.DIST_L2, 5)
    h = max(beta * cal.b0 / 2, 1.0)        # 深度门限跟着米粒宽度变，不低于 1 像素
    peaks = h_maxima(dist, h)              # 只留下足够深的山峰
    r = round(0.6 * cal.b0 / 2)            # 相距不到 0.6 倍短轴的峰算同一粒米
    seeds = label(cv2.dilate(peaks, disk(r))) * peaks
    if seeds.max() <= 1:                   # 只有一个种子，不用切
        return (mask > 0).astype(int)
    return watershed(-dist, seeds, mask=mask > 0)
\end{lstlisting}

\subsection{第五步，剔除非米区域、复核切分、找回漏掉的米}
\label{sec:correct}

这一步的几件事在程序里并不都排在切分之后，执行顺序见代码 \ref{code:count} 与图 \ref{fig:flow}。
每个连通域先过碎屑、异物、暗区三道关，剩下的才交给第三步判断是否粘连；
切开的粘连块再复核两件事；全部数完后，最后从开运算之前的阈值图里找回漏掉的米。
放在一节里讲，是因为它们回答的都是“这一块到底算几粒米”。
一个粘连块从切开到定出粒数的全过程见图 \ref{fig:cluster}。

\textbf{切分之前，先排除不是米的区域。}

一是忽略碎屑。面积不到 0.45 倍单粒的区域直接忽略。
这个门限原来是 0.3，粘连判据改用凸实度之后切开的块多了，切口处留下的 0.3 至 0.45 倍的碎片被计了数，才上调。

二是剔除异物。硬币、木框这类东西面积很大，但与米堆有两点不同。
米粒只是挨着，不会融成一体，所以米堆最厚处也只有一粒米那么厚，硬币和木框则厚得多。
这里的厚度用区域里能放下的最大圆的直径来量，记为宽度 $w$，单粒的宽度记为 $w_0$，见图 \ref{fig:criterion} 中的橙圈。
几粒米粘连通常会留下凹口，面积数倍于单粒却和单粒一样凸的区域，多半不是米堆。
这条判据起初还要求异物比米粒更圆，细长的木框条因此漏了过去，去掉这一条后才被挡住。

还有一类异物和米粒一样大小、一样形状，上面两条都拦不住。
一是木框、墙面这类亮背景边上的反光亮条，二是硬币浮雕被二值化后碎成的小块。
它们的共同点在周围。米粒躺在深色的底上，四周都是底；这些东西至少有一侧紧挨着亮的木头或硬币面。
所以在区域外围取一圈，从外 2 像素到约两粒米宽，看其中有多少背景像素是亮的。
“亮”要同时满足两个条件，一是比 Otsu 在背景上分出的阈值亮，二是比底色与米粒亮度的中点亮。
只用前者，整张图都是黑底时 Otsu 会把黑底本身劈成两半；只用后者，D3 里米粒发暗，中点跟着偏低。
亮像素超过两成就判为异物。

三是剔除暗区。不少图选中的二值化方案是“饱和度低的算前景”，可纯黑和白米一样饱和度低，
木框边的黑色阴影条和一些暗斑于是也成了前景，大小形状都和米粒差不多。
它们的灰度只有米粒的百分之几，米粒自身则在米粒中位灰度的 0.9 至 1.1 倍之间。
所以先取所有候选米粒的灰度中位数作为参照，平均灰度不到它一半的区域都当作异物。

\textbf{切开之后，复核切分结果。}

四是并回碎块。面积不到 0.4 倍单粒的碎块多半是切多了，把它并回与它接壤最多的那一块。

五是补切。切完后面积仍超过 1.5 倍单粒、凸实度又比单粒低 0.03 以上的块，说明没有切开。
先按面积算出它该有几粒，再取距离图上最高的那几个峰作种子重切一次。
切出的每一块大小都像一粒米才采用，否则只按面积计数。
起初这里只按面积计数，粒数大多对，但效果图上几粒米画成一整块。

\textbf{最后，找回被抹掉的米。}

六是找回。拿标注框逐粒核对漏掉的米，发现真正没被阈值分出来的只是少数，
大多数在阈值图里本是完整的一粒，是第一步去噪用的 $3\times3$ 开运算把它们削掉了。
D3 的米只有三四像素宽，一次开运算就能削掉大半甚至整粒抹掉，剩下的部分又被碎屑门限丢弃。
直接去掉开运算不行，噪点会跟着涌进来，D3 的误差反而升到 5 粒以上。
所以在最后补一步，回到开运算之前的阈值图，找那些既没被计数、也没被判为异物的区域，
面积在单粒的 0.3 至 1.3 倍之间，宽度不小于单粒的一半，长宽比不超过单粒的三倍，
亮度不低于米粒的一半，且不挨着亮背景，就补记一粒。
这里的单粒面积也在开运算之前的阈值图上量，否则会被开运算缩小的尺寸带偏。

碎屑门限 0.45、亮背景判据的两成、暗区判据的一半，以及找回时面积和宽度的两个下限，
都只在 D1 上选定，D3 没有参与挑选，结果在 D3 上同样有效，详见第 \ref{sec:ablation} 节。

\begin{lstlisting}[float=!htbp, caption={计数主循环}, label={code:count}]
total = 0
for c in components:
    if c.area < 0.45 * a0:                 # 碎屑，忽略
        continue
    if is_foreign(c, cal) or near_bright(c, cal, bright) or is_dark(c, gray, ref):
        continue                           # 硬币、木框、亮边、阴影等，不计数
    if not is_touching(c, cal):            # 单独的一粒
        total += 1
        continue
    parts = merge_small(split_cluster(c.mask, cal), a0)  # 小于 0.4*A0 的碎块并入邻居
    for p in regionprops(parts):
        k = p.area / a0
        if k < 0.4:                        # 没有邻居可并的碎块
            continue
        if k > 1.5 and p.solidity < cal.rho0 - 0.03:
            n = round(k)                   # 没切开，按面积它该有 n 粒
            pieces = split_by_count(p.mask, n, cal)   # 取最高的 n 个峰重切一次
            if pieces_look_like_grains(pieces, a0):
                parts_drawn.extend(pieces)            # 切对了就按切开的画
            total += n                     # 粒数都按 n 计
        else:
            total += 1
total += len(recover_erased(raw_mask, counted, ref))  # 找回被开运算抹掉的米
\end{lstlisting}

\section{方法一的实验与分析}

这一节用实验回答五个问题。方法一比常见做法准多少，粘连加重时还准不准，
图像变差时从哪里开始失效，每一步各起多大作用，以及和视觉大模型 SAM 3 相比差在哪里、省在哪里。

\subsection{数据集}

D1、D3 两组数据以及 D2 所用的米粒素材，都取自 Roboflow Universe 上的公开数据集，许可为 CC BY 4.0。
第 \ref{sec:student} 节的方法二沿用这三组数据。

\textbf{D1，真实照片，51 张。} 取自 Roboflow 上的 rice 数据集\cite{ds_d1}，
手机拍摄，深色布上摊开的米粒，每张 71--124 粒，带一枚参照硬币，每粒米都有人工标注框。
米粒基本不粘连。

\textbf{D2，自制合成图，40 张。} 从 RICE 数据集\cite{ds_grains}中 Karacadag 品种的单粒米照片里
抠出米粒，随机旋转、缩放后贴到深色画布上，
粘连率分 0\%、20\%、40\%、60\%、80\% 五档，每档 8 张，每张 44--98 粒。
它的真值由构造方式精确给定，粘连程度也可控，专门用来考粘连。

\textbf{D3，低分辨率，719 张。} 取自 Roboflow 上的 RICE 数据集\cite{ds_d3}，
$224\times224$ 的小图，每张约 14 粒。该数据集导出时做过翻转增强，同一源图存在多个副本，
按源图名去重后保留 719 张。

\subsection{评价指标}

记第 $k$ 张图的真值为 $g_k$、预测为 $p_k$。
主要指标为平均绝对误差 $\mathrm{MAE}=\frac1n\sum_k|p_k-g_k|$，即平均每张数错几粒。
另外给出准确率 $1-\mathrm{MAPE}$ 与最差单张误差，
其中 MAPE 为平均相对误差 $\frac1n\sum_k|p_k-g_k|/g_k$。
平均值小并不排除个别图像错得离谱，所以两者一并看。

\subsection{与其他方法比较}

先看方法一比常见做法准多少。
为使比较只落在“如何分开粘连”这一步上，所有方法都跑在同一份二值图上。
B1 直接统计连通域个数，不对粘连作任何处理。
B2 用前景总面积除以单粒面积。
B3 是距离变换注水分割，种子取 $D > 0.5\max D$，这是 OpenCV 教程的做法。
B4 腐蚀后取连通域作种子，即文献\cite{kurade2023}的做法。
B5 为轮廓凹点 + 椭圆拟合\cite{avzalov2025}。

结果见表 \ref{tab:comparison}。三组数据上，方法一的平均误差都是六种几何方法中最低的。
三种对比方法的失效值得单独说一下。

B4 在合成数据上除不粘连的一档外，误差与 B1 完全相同。一次 $3\times3$ 腐蚀不足以分开粘连块，
每块仍只产生一个种子，注水分割什么也没切开，等于退化成连通域计数。

换一种米粒尺度，这些数字就不再合适，方法一的判据从图像自身量出，所以在三组数据上表现都比较稳。

\subsection{图像质量变差时的表现}
\label{sec:robust}

这一小节找方法一的失效边界。本文在 D2 上人为施加模糊、噪声、对比度压缩与降采样四类退化，
结果见表 \ref{tab:robust}，其中模糊强度以单粒宽度 $b_0$ 为单位。

噪声加到 45 个灰度级、对比度压到 8\%，误差基本没有上升。
降采样到 1/6 时米粒只剩约 4 像素宽，中位误差为 2 粒，误差逐步上升而不是突然失效。
模糊则不同。轻度模糊，即 0.20 至 0.35 倍 $b_0$ 时，中位误差仍在 2 粒以内，平均误差却暴涨，

模糊到 0.70 倍 $b_0$ 时，中位误差也升到 15 粒，40 张里有 13 张崩溃。
所以方法一怕的是模糊图像。

合并种子碎块管的是切分本身。不合并时，D2 的误差从 0.25 粒涨到 3.17 粒，
一粒米常被切成两半。修正前的写法不合并碎块，只好把 $\beta$ 抬到 0.45 来压住碎块，
代价是许多粘连块切不开，D2 的误差为 1.77 粒。

形状先验校正，也就是按面积补数，兜底的是注水分割仍没切开的那些块。
去掉它，D2 的误差从 0.25 粒涨到 1.12 粒，D1 从 2.75 粒涨到 4.45 粒。

异物剔除管的是 D3 的木框。去掉它，D3 的误差从 0.50 粒涨到 2.00 粒。
暗区判据管的是被当成前景的阴影，去掉它，D1 从 2.75 粒涨到 3.53 粒，D3 从 0.50 粒涨到 0.90 粒。
找回被开运算抹掉的米，去掉它，D1 涨到 4.22 粒，D3 涨到 0.74 粒。
亮背景判据则只在 D1 上起作用，去掉它 D1 涨到 3.25 粒；D3 上木框边的东西大多是阴影，
已被暗区判据挡住，去掉亮背景判据反而略好，为 0.45 粒。

粘连判据在细米粒上若退回厚度判据，D1 的误差从 2.75 粒涨到 4.51 粒，D3 则降到 0.38 粒。
碎屑门限退回 0.3，D1 几乎不变，D3 涨到 0.66 粒。

尺度自标定管的是真实照片里参差的米粒大小。改成整个数据集共用一个 $A_0$ 后，
D1 的误差从 2.75 粒涨到 6.31 粒。D2 反而从 0.25 粒降到 0.17 粒，
因为合成图的米粒本来就大小整齐，一个固定值比每张图现量更稳。

只用灰度通道时 D1 更好，为 2.33 粒，但 D3 从 0.50 粒升到 1.00 粒，它仍需要饱和度通道，所以候选通道仍都保留。

表中有好几项在 D3 上反而更好，除上面说的亮背景判据和厚度判据，
还有去掉形状先验校正与去掉尺度自标定，D3 分别为 0.42 与 0.47 粒。
它们都让 D1 明显变差。本文的取舍只看 D1，D3 留作检验，
若按 D3 上的表现回头改设置，D3 就不再是没参与挑选的数据了，所以没有改。
粘连判据改成“或”后 D2 略降，种子碎块不合并且 $\beta$ 取 0.45 时 D1 略降，但都让其他数据变差。

这几步各管一类问题。去掉其中哪一步，都有一组数据明显变差。

\subsection{本节小结}

方法一在三组数据上都比五种常见做法准，粘连加重时误差也几乎不上升，在真实照片上比 SAM 3 还准。
它的弱点有三处，一是怕模糊，二是在低分辨率的 D3 上仍不及 SAM 3，为 0.50 对 0.07 粒，
三是二值化方案一旦选错就整张失败，D3 里有 8 张图因此只数出 0 至 4 粒。
SAM 3 在低分辨率图上更准，却要挑提示词、要显卡。
能不能兼得两者之长？这引出了第二种方法。

\section{方法二：SAM 3 作为教师模型训练专用小模型}
\label{sec:student}

\subsection{方法二思路的由来}

第二种方法是在方法一还比较粗糙的时候想到的。那时方法一在低分辨率的 D3 上误差 1.90 粒，
零样本的 SAM 3 用提示词 grain、阈值 0.35，只有 0.18 粒。方法一的失败主要有两类，木框边上的东西被当成米，颜色偏暗的米被漏掉。
后来逐粒核对才查清，前者多是黑色阴影，后者多是被开运算抹掉的米，
补上第 \ref{sec:correct} 节的几条判据后，方法一在 D3 上降到 0.50 粒。

但有一类失败是几何判据补不上的。方法一先要挑一个二值化方案，挑错了整张图就全错。
归根结底，几何判据只知道米长什么样，并不知道什么是米。
既然 SAM 3 知道，能否把它知道的东西教给一个小模型？

\subsection{具体实现方式}

\textbf{制作图片标注：} 用 SAM 3 处理每张照片，取其每个掩膜的质心，得到一串点坐标作为伪标签。
合成图 D2 则直接采用生成时记录的米粒中心，不必经过教师。
教师取提示词 white seed、阈值 0.40。拿它与人工标注逐点匹配，教师给出的点在 D3 上准确率 0.993、召回率 1.000、计数误差 0.10 粒，
在 D1 上依次为 0.957、0.967 与 3.29 粒。逐点看，这两组数据上的伪标签足够干净，
但 D1 上的计数误差并不比方法一小。
人工标注全程不参与训练，只用于测试。
图 \ref{fig:teacherlabel} 是其中一张照片的逐点对照，漏掉的和多给的都是少数。

让它在米粒处“鼓起一个包”却是可行的。
其二，损失函数不依赖于把相邻两粒分开，而那恰是几何方法最吃力之处。
高斯的宽度按每张图自身的米粒间距确定，因此 4 像素与 25 像素的米粒在网络看来尺度相当。

\subsection{结果}

结果见表 \ref{tab:student}。为便于比较，表中一并列出了不作任何粘连处理时
直接统计连通域的结果 4.46 粒，四者测的是同一批图。
学生模型的总体误差为 0.68 粒，不及方法一的 0.48 粒。
在训练数据最多的 D3 上两者接近，学生模型为 0.42 粒，方法一为 0.38 粒；D1 和 D2 上方法一明显更好，
学生模型分别为 3.91 与 1.29 粒，方法一为 2.00 与 0.25 粒。
它仍不及教师的 0.25 粒，这符合预期，蒸馏一般不会超过教师。
但它只有 27 万参数、1 MB 权重，约为 SAM 3 的三千分之一。
每张图耗时 2 至 25 ms，比 SAM 3 快 8 到一百多倍，见表 \ref{tab:cost}。
更要紧的是不必挑选提示词。SAM 3 换一个提示词就可能一粒也检不出，
学生则把选定的那套行为固化了下来。

学生模型的长处不在平均误差，而在不会整张失败。图 \ref{fig:studentwin} 是 D3 上的一个例子。
方法一挑二值化方案时选错了，选出的前景是两侧的木框而不是米粒，木框又被判为异物，全图数出 0 粒，真值为 16 粒。
学生模型没有“挑二值化方案”这一步，密度图上 16 粒米各鼓起一个包，积分得 16.5 粒。
它没有用到更多的形状判据，只是从教师那里学到了米粒该是什么样子。

\section{不足}
\label{sec:limit}



\textbf{画面里有比米更整齐的东西时，会把它当成米。}
我另找过一组带直尺的照片\cite{ds_ruler}，想补充粘连数据。
结果在不少图上，程序选出的前景是直尺的刻度，而不是米粒，见图 \ref{fig:scope}。
原因在于式 \eqref{eq:score} 挑二值化方案时，看的是画面里有多少块大小一致的小东西。
刻度线大小整齐、对比强烈，比颜色浅、大小不一的米粒更符合这个标准。
换句话说，方法一只认形状，不认得什么是米。
这组照片里还有不少是几个品种的米放在一起对比，粒径相差很大，
不符合“同一张图里米粒大小相近”这一前提，所以最终没有用作测试集。

\begin{cfigure}
  \includegraphics[width=\textwidth]{scope_failure.png}
  \caption{方法被直尺刻度误导的两个例子，每例左为原图、右为选出的前景。}
  \label{fig:scope}
\end{cfigure}

\textbf{图像模糊时，可能选错二值化方案。}
第 \ref{sec:robust} 节里出现崩溃的几张图，都是模糊造成的。
模糊之后，饱和度通道被阈值切成大量小碎点。
碎点数目多，式 \eqref{eq:score} 的得分反而略高于正确的方案，程序便选错了，一张图数出上千粒。
这个问题目前还没有解决。

\textbf{二值化选错时会整张失败。}
二值化方案按整张图打分，个别低分辨率图上选出的前景干脆是木框而不是米粒，
木框又被判为异物，一张图数出 0 粒，见图 \ref{fig:studentwin}。
这需要改二值化的候选或打分方式，目前还没有做。

\textbf{几个门限是在测试数据上选的。}
第 \ref{sec:correct} 节中碎屑、亮背景、暗区与找回的几个门限，都是在 D1 上逐个试出来的。
D3 没有参与挑选，在它上面的误差从 1.90 粒降到 0.50 粒，可以看作留出集上的结果。
这些门限是分两轮加入的。每一轮也都试过反过来只用 D3 挑选，这时 D1 的误差分别为 3.57 与 2.88 粒，
比在 D1 上挑选时的 3.24 与 2.71 粒高出约一成和不到一成，门限对挑选用的数据仍有些迁就。
但 D1 上的数字仍带着调参的成分，换一批照片未必这么准。





\section{结论}

本文实现了一种基于注水分割的粘连米粒计数方法。它先由图像自身量出单粒米的尺度，
据此判断粘连、控制种子数量，最后按面积与形状复核切分结果。
三组数据上的平均绝对误差分别为 2.75、0.25 与 0.50 粒，优于五种对比方法。

做完这份作业，体会最深的一点是，这个问题没有想象中这么简单，我看到问题的第一眼，认为只要对二值化图像稍加处理即可。但遇到了挫折，于是我去网上搜集论文，看看有没有好的方法可以参考。受到了分水岭算法的启发，针对这个问题具体化，于是有了方法一。对于方法二，是一种偷懒的黑箱做法，平均误差反倒不及方法一，但不会因二值化选错而整张失败，可解释性则弱。我做大创项目时用过 SAM 3 分割模型，于是有了蒸馏学生模型的想法。
